# DragonLoot Onyx

An unofficial Forge port of [DragonLoot for Fabric](https://github.com/GitPois1x/DragonLoot), for Minecraft 1.18.2.

Defeat the Ender Dragon for scales and use them to upgrade armor, tools, weapons, horse armor, and anvils. Combine a dragon chestplate with an elytra to glide.

## Differences from the original

- Use the vanilla smithing table to upgrade compatible gear with dragon scales and combine a dragon chestplate with an elytra.
- The dragon shield has a configurable disable cooldown, set to 40% of the standard duration by default.
- The dragon sword has a configurable melee reach bonus of 0.5 blocks by default.
- The dragon axe adds 1 second to the cooldown of shields it disables by default.
- The dragon trident can use Riptide in water, lava, and modded liquids.
- This port uses vanilla gear for upgrades that can take Netherite Plus gear in the Fabric original.

## Installation

Use Minecraft 1.18.2, [Forge 40.3.12 or later in the 40.x series](https://files.minecraftforge.net/net/minecraftforge/forge/index_1.18.2.html), and Java 17. Install the JAR on both client and server for multiplayer.

For in-game settings, install [Cloth Config for Forge 1.18.2](https://www.curseforge.com/minecraft/mc-mods/cloth-config/files/5729090) and open **Mods → DragonLoot Onyx → Config**.
