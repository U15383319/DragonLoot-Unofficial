# DragonLoot Onyx

An unofficial Forge port of [DragonLoot for Fabric](https://github.com/GitPois1x/DragonLoot), for Minecraft 1.19.2.

Defeat the Ender Dragon for scales and use them to upgrade armor, tools, weapons, horse armor, and anvils. Combine a dragon chestplate with an elytra to glide.

## Differences from the original

- Dragon upgrades use a dedicated smithing template found in End City treasure chests. Duplicate it with seven amethyst shards, a purpur block, and an existing template.
- The dragon shield has a configurable disable cooldown, set to 40% of the standard duration by default.
- The dragon sword has a configurable melee reach bonus of 0.5 blocks by default.
- This port uses vanilla gear for upgrades that can take Netherite Plus gear in the Fabric original.

## Installation

Use Minecraft 1.19.2, [Forge 43.5.2 or later in the 43.x series](https://files.minecraftforge.net/net/minecraftforge/forge/index_1.19.2.html), and Java 17. Install the JAR on both client and server for multiplayer.

For in-game settings, install [Cloth Config for Forge 1.19.2](https://www.curseforge.com/minecraft/mc-mods/cloth-config/files/5729096) and open **Mods → DragonLoot Onyx → Config**.
