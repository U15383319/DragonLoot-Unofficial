# DragonLoot Onyx

An unofficial NeoForge port of [DragonLoot for Fabric](https://github.com/GitPois1x/DragonLoot), for Minecraft 1.21.1.

Defeat the Ender Dragon for scales and use them to upgrade armor, tools, weapons, horse armor, and anvils. Combine a dragon chestplate with an elytra to glide.

## Differences from the original

- Dragon upgrades use a dedicated smithing template found in End City treasure chests. Duplicate it with seven popped chorus fruit, an obsidian block, and an existing template.
- The dragon shield has a configurable disable cooldown, set to 40% of the standard duration by default.
- The dragon sword has a configurable melee reach bonus of 0.5 blocks by default.
- The dragon mace grants 10% knockback resistance in the main hand by default and can be repaired with dragon scales.
- The dragon axe adds 1 second to the cooldown of shields it disables by default.
- The dragon trident can use Riptide in water, lava, and other NeoForge liquids.
- This port uses vanilla gear for upgrades that can take Netherite Plus gear in the Fabric original.
- The dragon anvil charges 80% of the normal cost, up to 30 levels by default. Both values are configurable.

## Installation

Use Minecraft 1.21.1, [NeoForge 21.1.266 or later in the 21.1 series](https://projects.neoforged.net/neoforged/neoforge), and Java 21. Install the JAR on both client and server for multiplayer.

For in-game settings, install [Cloth Config 15 for NeoForge](https://www.curseforge.com/minecraft/mc-mods/cloth-config/files/5623420) and open **Mods → DragonLoot Onyx → Config**.
